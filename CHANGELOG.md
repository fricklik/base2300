# Changelog

## 0.1.0 — initial standalone release preparation

- Extract the portable codec from the original private project with its
  existing alphabet and checked/basic and experimental/minimal wire formats.
- Expose a server-free ESM/TypeScript API and a binary-safe Node.js CLI.
- Add reproducible comparisons, format documentation, fixed vectors, CI and a
  local interactive playground.
- Keep the legacy LLM mode reserved and reject it explicitly.
- Reject trailing bytes after native Brotli streams, matching the existing
  DEFLATE strictness check while preserving valid portable wire output.

This entry records the prepared source release; it does not assert that an npm
package, GitHub release or hosted playground has been published.

### Unreleased

- Replace the inherited Japanese sample sentence with an English one
  (`Base2300 packs the same bytes into fewer characters.`) in the README,
  playground, browser check, tests and the checked v1 known-answer table. The
  new checked vector was cross-checked with an independent Python
  implementation; the short-Unicode vectors were regenerated by this
  implementation and are guarded by round trips. Wire format unchanged.
- Translate source, test, demo and script comments from Japanese to English.
  Runtime strings, error messages and the playground UI text are unchanged.
- Record the public repository, first CI matrix run and browser verification.
- Export the alphabet building blocks `BASE64_ALPHABET`, `JOYO_KANJI` and
  `BASE2200_ALPHABET` from the root entry so downstream projects can derive
  tables without copying the data.
- Add `prepublishOnly` (runs `npm run check`) and a tag-driven
  `publish.yml` workflow that publishes through npm Trusted Publishing (OIDC).
  The first release is still published manually; see `docs/releasing.md`.
- Playground: English is now the default UI language. A header toggle switches
  to Japanese; the choice persists in `localStorage` and `?lang=ja` / `?lang=en`
  override it. Worker notes, labels and error messages follow the page language.

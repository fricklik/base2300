How few characters
can hold the same data?

A small lab that repacks the same information into 2,300 symbols.
It puts character count and byte size side by side and checks that the conversion is reversible.

The checked format detects accidental corruption with a checksum. It does not encrypt.

01

Measure what shrinks.

Even when characters go down, UTF-8 bytes can go up. Short inputs and emoji can grow in character count too.

02

Keep the data intact.

Every conversion is checked against the original bytes. CRC-free formats may not detect later typos or corruption.

03

Start from curiosity.

For homemade tools with code-point limits, learning Unicode and comparing encodings. Check how the destination counts and preserves characters before relying on it.
